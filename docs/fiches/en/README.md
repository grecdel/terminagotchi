# Lesson sheets

For schools, clubs and families: one sheet per learning path of the game, generated from the lessons
themselves (`python3 donnees/generer_fiches.py`). Each sheet gives the duration, objectives, the plan
step by step and questions to ask. Pupils are followed with the website's **class mode**.
