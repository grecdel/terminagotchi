# Terminagotchi — Android

Une créature en pixel art qui se nourrit des commandes que tu tapes, et qui t'apprend le terminal.

## Installer
1. Ouvre la page **Releases** de ce dépôt sur ton téléphone.
2. Télécharge `terminagotchi.apk` et ouvre-le (autorise l'installation si Android le demande).
3. Appui long sur l'écran d'accueil → **Widgets** → **Terminagotchi**.
4. Touche **⌨ Terminal** : le panneau s'ouvre avec le clavier. Baptise ta créature et tape `ls` !

## Jouer
- Chaque commande tapée la nourrit et lui donne de l'XP (les commandes collées ne comptent pas).
- Elle te donne des leçons au fil de sa croissance : navigation, dossiers, fichiers, protections, ménage.
- Elle évolue (Œuf → Bébé → Ado → Adulte) selon les commandes que tu utilises le plus.

Chaque modification du code fabrique automatiquement une nouvelle version dans les Releases.
